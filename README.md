# 10. Консолидация данных и расчёт вознаграждений

**Бизнес-задача:** Как объединить разрозненные выгрузки и правильно рассчитать выплаты по установленным условиям?

Решение тестового задания: консолидация выгрузок Услуги, уникальные пациенты по клиникам и каналам, расчёт вознаграждений направившим представителям.

**В репозитории только полностью синтетические данные.** Они созданы отдельно и не являются заменой ФИО или ID в реальной выгрузке. Исходные медицинские данные и полное решение по ним хранятся локально и в GitHub не опубликованы.

## Правила задачи

Возраст ≥ 18 означает «взрослые», иначе «дети». Непустой представитель после очистки пробелов даёт канал «от Агентов», иначе «Реклама».

Сначала суммируются компенсации одного пациента за месяц. В июле 2024 года ребёнок с оплатой строго больше 100 000 ₽ приносит представителю 5 000 ₽. В августе и сентябре пациент любого возраста с оплатой строго больше 120 000 ₽ приносит 8 000 ₽. Выплата производится один раз за пациента в месяц при наличии представителя. Несколько представителей или смена возрастной категории внутри месяца требуют отдельного решения и вызывают ошибку.

Месяц задаётся датой услуги. Для суммы выплаты используется вся компенсация пациента за месяц, включая строки разных клиник. Наличие одного представителя в части строк пациента рассматривается как отнесение месячного пациента к нему; это явное допущение задачи.

## Результаты демонстрации

| Месяц | Строк услуг | Разных пациентов | Компенсация, ₽ | Пациентов с выплатой | Выплата, ₽ |
| --- | ---: | ---: | ---: | ---: | ---: |
| 2024-07 | 5 | 4 | 560 000,00 | 1 | 5 000 |
| 2024-08 | 7 | 5 | 640 001,00 | 2 | 16 000 |
| 2024-09 | 4 | 4 | 570 000,01 | 2 | 16 000 |
| Весь период | 16 | 12 | 1 770 001,01 | 5 | 37 000 |

Сумма месячных уникальных пациентов равна 13, а за период — 12: D001 встречается в двух месяцах. В августе D008 посещает две клиники и должен учитываться в каждой. Общие итоги сводной отключены, чтобы сумму групп не принять за число людей по сети.

## Как открыть и обновить

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте.
2. Откройте готовый XLSX в настольном Excel с поддержкой Power Query. Сохранённые результаты доступны без обновления.
3. На листе **Параметры** в B2 замените `C:\Services_DEMO` на полный путь к распакованной папке с тремя файлами `Services_*.xlsx`.
4. Выполните **Данные → Обновить всё**, дождитесь завершения запросов, затем обновите сводную отдельно.
5. Сопоставьте выплаты с таблицей выше. Изменение порогов в справочном блоке параметров само по себе не меняет правила: условия заданы в M и формулах.

Листы: «Итоги», «Сводная», «Вознаграждения», «Пациент месяц», «Услуги», «Уникальные», «Параметры». Источник сводной предварительно очищен от повторов по месяцу, клинике, каналу и ID, поэтому обычное количество ID равно нужному числу уникальных пациентов внутри ячейки.

## Воспроизведение проверки без Excel

Python 3.11+:

```bash
python -m pip install -r requirements.txt
python analyze.py . --out qa/analysis.json
python audit.py . .
```

Excel-книга уже собрана и не требует Python для просмотра или обновления. `build_workbook.mjs` использует `@oai/artifact-tool` из среды Codex и включён для прозрачности авторинга; это не общедоступная зависимость установки через requirements.txt. `add_native_features.py` добавляет Power Query и PivotTable средствами OOXML после авторинга книги. Рабочий M-код доступен отдельно, его можно восстановить через расширенный редактор Excel по конспекту.

## Проверки и ограничения

Сверены строки, компенсации, выплаты по пациентам, уникальные пациенты в группах, сохранённые результаты формул, кэш PivotTable, шесть подключений Power Query, XML и ссылки внутри XLSX. Тесты проверяют строгие пороги, возраст 17,99 и 18 лет, пустого представителя и суммирование нескольких услуг.

**Настольный Excel в среде подготовки отсутствует.** M-код, обновление подключений и поведение сводной в установленной версии Excel здесь не запускались. Программная проверка структуры не заменяет первый запуск обновления в Excel. Стандартный PNG-рендерер среды возвращал пустое изображение; визуальная проверка выполнена запасным просмотром сохранённых ячеек, который также не заменяет движок Excel.

Условия определены только для июля–сентября 2024 года. Для другого месяца требуется явно задать политику выплаты и расширить отчёт, а не переносить правило автоматически.
